# Components

Reusable Svelte components.

## Purpose

- Encapsulate UI logic
- Provide reusable interface elements
- Follow component-driven development

## Structure

```
components/
├── Dialer.svelte           # Dial pad component
├── ActiveCall.svelte       # Active call UI
├── CallControls.svelte     # Answer/hangup/mute buttons
├── AudioDeviceSelector.svelte  # Audio device picker
└── ContactList.svelte      # Contact list (post-MVP)
```
